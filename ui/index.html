Deine Server und Modelle

Server prüfen, Modelle entdecken und gezielt aktivieren.

Server hinzufügen oder aktualisieren

Automatische Erkennung liest die Modelllisten von Ollama und OpenAI-kompatiblen Chatservern. ComfyUI nutzt seine eigene API: Workflow importieren, Eingänge zuordnen und Bilder erzeugen. OpenAI-kompatible Bildserver verwenden eine andere Verbindungsart.

Wird verschlüsselt im Windows-Tresor abgelegt. Ein leeres Feld behält einen vorhandenen Zugang für dieselbe Adresse bei.

HTTPS schützt die Übertragung. Die HTTP-Ausnahme ist unverschlüsselt und nur für private IP-Adressen zulässig. Eine VPN-Verbindung wird von der App nicht automatisch geprüft.

ComfyUI-Workflow zuordnen

Wähle die direkten editierbaren Eingänge aus deinem API-Workflow. Verknüpfte Eingänge bleiben erhalten. Der Ausgabe-Node muss Bilder im output-Ordner speichern.

Die Bildparameter stellst du anschließend direkt im Chat ein. Eine neue Workflow-Datei setzt die Zuordnung zurück und deaktiviert das Backend bis zur erneuten Einrichtung.

Ein Schalter steuert die Nutzung in dieser App. Modelle auf dem Server bleiben erhalten. Beim Serverwechsel wird der ausgewählte Kontext des bisherigen Chats mitgeschickt. Beginne für getrennte Inhalte ein neues Gespräch.

Neue Ollama-Verbindung

Chat: Kreativität und Antwortlimit werden übermittelt. Bei OpenAI-kompatiblen Servern begrenzt das Kontextfenster die mitgesendete Historie; die Server-Kontextgröße stellst du dort ein. Bildeingaben benötigen eine gemeldete Vision-Fähigkeit. Neue Modelle bleiben deaktiviert. Entfernte Modelle werden beim Start nicht wieder hinzugefügt.

Dein verschlüsselter Tresor

Verbindungen, Zugänge und Historie werden außerhalb des Projektordners verschlüsselt gespeichert.

Windows-Schutz aktiv

Der Schlüssel wird durch dein Windows-Benutzerkonto geschützt. Es gibt keinen Klartext-Ersatzspeicher.

Übertragung und fremde Server

Zugangsdaten nur über HTTPS mit gültigem Zertifikat. Keine Weiterleitungen mit Schlüsseln. Dein bestehender HTTP-Server ist eine ausdrücklich erlaubte Heimnetz-Ausnahme.

Ein fremder Serverbetreiber kann die gesendeten Chat-Inhalte sehen. Nutze einen eigenen, widerrufbaren Zugang für diese App.

Authenticator · Konzept

Ein Einmalcode kann später eine Sitzung zusätzlich freigeben. Für einen eigenen App-Zugang ist eine separate Einrichtung erforderlich. Der wechselnde Code ist kein Schlüssel zur Verschlüsselung.

Geplant: unabhängiges Tresorpasswort oder Windows Hello, optional Authenticator, automatische Sitzungssperre und Wiederherstellung. Diese zusätzliche Freigabe ist noch nicht implementiert.

Während der Nutzung braucht die App entschlüsselte Daten im Arbeitsspeicher. Windows-Schutz verhindert keine Zugriffe durch Schadsoftware unter deinem bereits angemeldeten Konto. Bereits vorhandene Klartextkopien auf Datenträgern lassen sich nachträglich nicht garantiert sicher löschen.

Deine Version

Veröffentlichung & Installation

Öffentliche GitHub-Releases werden ohne Zugangsschlüssel geprüft. Release-Entwürfe erscheinen nicht als Updates.

Diese Pilotversion ist noch nicht mit einem Windows-Herausgeberzertifikat signiert. Die Installation aus der App ist deshalb gesperrt. Neue Setup-Dateien kannst du manuell über die bestehende Installation installieren, sofern Windows ihre Ausführung erlaubt.

Programm: frei wählbarer Installationsordner. Daten: Windows-Tresor unter LocalAppData\QwenChat\Vault. Auch eine Deinstallation bewahrt den Tresor. Er ist an dein Windows-Benutzerkonto gebunden; eine Kopie allein ist keine portable Wiederherstellung.
