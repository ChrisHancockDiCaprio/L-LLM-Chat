# KAIROS 0.3.2

Buildkorrektur für die Veröffentlichung von 0.3.1: Der Windows-Installer wird ohne unnötigen Neuaufbau optionaler nativer SSH-Beschleuniger erstellt. SSH verwendet die getestete JavaScript-Implementierung. Die NSIS-Anpassung bleibt auf den Build-Hauptprozess begrenzt.

Enthält sämtliche Funktionen von 0.3.1: SSH-Tunnel, sichere Hostschlüsselprüfung, kein automatischer Abbruch nach 240 Sekunden und verschlüsselter ComfyUI-Auftragswiederabruf. Chats, Zugangstresore und Workflowprofile bleiben erhalten.

86 Tests bestanden bereits im GitHub-Build für 0.3.1; GitHub prüft erneut und erstellt EXE- und MSI-Installer. Details: SSH-UND-AUFTRAEGE.md.

Weiterhin unsignierte Windows-Pilotversion: Update herunterladen und Setup manuell installieren.
