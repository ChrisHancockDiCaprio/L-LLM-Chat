# Design-Skills für Claude Code

Diese Skills lädt Claude Code in jeder Session dieses Repos automatisch. Sie greifen, sobald es um Gestaltung, Animationen oder Übergänge geht.

| Skill | Wofür | Quelle | Lizenz |
|---|---|---|---|
| `frontend-design` | Eigenständige, nicht schablonenhafte Gestaltung: Typografie, Farben, Layout, Texte | [anthropics/skills](https://github.com/anthropics/skills) @ `2c5958e` | Apache 2.0 |
| `motion-design` | Animationen mit Gefühl: Timing, Easing, Choreografie, Disney-Prinzipien, Seitenwechsel | [lottiefiles/motion-design-skill](https://github.com/lottiefiles/motion-design-skill) @ `f9a8a04` | MIT |
| `design-motion-principles` | Animationen bauen (Create) oder bestehende prüfen (Audit), Barrierefreiheit inklusive | [kylezantos/design-motion-principles](https://github.com/kylezantos/design-motion-principles) @ `4a9ca87` | MIT |

Die Skills sind unverändert übernommen. Für ein Update den jeweiligen Ordner aus dem Quell-Repo neu kopieren.
